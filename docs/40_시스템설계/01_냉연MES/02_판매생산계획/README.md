# 판매·생산계획

수주·수요와 가용 재고를 바탕으로 계획을 편성하고 확정·변경하는 업무를 다룬다.

- **기능 후보** · MTO·MTS 물량 구분, 계획 버전 비교, 최적화 결과 검토·채택
- **설계할 때 정할 점** · 엔진 추천을 현업이 수정할 수 있는 범위와 이미 지시된 작업의 변경 처리를 결정한다.
- **연관 업무** · [납기관리](../03_납기관리/README.md) · [생산계획최적화엔진](../../03_위성시스템/02_생산계획최적화엔진/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
