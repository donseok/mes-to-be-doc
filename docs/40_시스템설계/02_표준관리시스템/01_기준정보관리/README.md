# 기준정보관리

코드 집합, 코드값, 속성 간 관계를 등록·조회·정정하는 기능을 설계한다. 자재·품질 규격 등 업무별 데이터에 대해 표준관리시스템이 관리할 정의, SAP에서 받을 속성, MES가 현장에서 보완할 속성을 항목별로 결정한다.

- **기능 후보** · 코드 집합 등록, 중복 코드 검토, 사용기간·폐기 이력 조회, 영향받는 시스템 조회
- **인수 조건 검토** · 중복 키, 유효기간 중첩, 폐기 코드의 과거 생산 이력 조회, 수신처에 아직 적용되지 않은 버전의 표시
- **연계** · [변경승인과 배포](../03_변경승인과배포/README.md) · [MES 기준정보](../../01_냉연MES/01_기준정보/README.md)

확정한 기능은 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
