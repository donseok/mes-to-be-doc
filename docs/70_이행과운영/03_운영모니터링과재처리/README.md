# 운영 모니터링과 재처리

운영 담당자가 지연·불일치를 발견하고 처리 내역을 인계할 수 있도록 업무 상태, 조회 키, 알림 담당과 판정 근거를 기록한다. 아래는 감시 후보이며 임계값·담당·허용되는 재처리 방법은 운영 인수에서 확정한다.

| 시스템 | 예시 상태와 조회 키 |
|---|---|
| 표준관리시스템 | 배포 버전별 수신처의 마지막 반영 시각과 미반영 코드 |
| 냉연 MES | 작업지시·코일별 마지막 실적, 상대 시스템 응답 대기 상태와 메시지 식별자 |
| 파트너 포털 | 위탁 접수 번호별 전송·접수·반려 상태와 원요청에 대한 정정 이력 |
| 생산계획 최적화엔진 | 실행 번호별 입력 버전, 계산 완료 여부, MES의 결과 수신 및 채택 상태 |

재처리 기록에는 업무 키, 송수신 양쪽의 마지막 상태, 중복 반영 방지 조건, 판단자, 재처리 건과 최초 건의 연결, 사후 대사 결과를 남긴다. 수신 결과가 불명확한 건은 승인된 계약의 상태 확인·복구 절차를 연결한다. 운영자가 입력할 시스템별 명령과 권한은 담당 부서에서 승인한 운영 문서로 연결한다.
