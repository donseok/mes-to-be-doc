# 조업관리

공정별 작업 시작·종료, 투입·산출 실적, 코일 분할·합권 이력을 다룬다.

- **기능 후보** · 작업 실적 등록, 코일 계보 추적, 실적 정정·취소
- **설계할 때 정할 점** · 부분 실적과 계량 오차, 중복 실적 수신, 후속 공정 진행 후의 정정 절차를 정한다.
- **연관 업무** · [라인투입관리](../05_라인투입관리/README.md) · [생산관제](../07_생산관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
