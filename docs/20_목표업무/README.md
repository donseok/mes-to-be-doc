# 목표 업무

한 건의 주문, 코일, 표준 변경 또는 계획안이 시스템과 부서 사이를 어떻게 이동하는지 기록한다. 다음은 설계 착수용 업무 흐름이다. 단계·소유자·예외가 확인되면 기능 설계와 계약을 연결한다.

| 업무 흐름 | 먼저 맞춰야 할 경계 |
|---|---|
| [수주부터 출하](01_수주부터출하/README.md) | 영업 주문 검증, 생산·품질판정, 코일 배정과 출고 |
| [표준 변경과 적용](02_표준변경과적용/README.md) | 표준의 적용일과 각 시스템의 반영 시점 |
| [협력사 가공과 입출고](03_협력사가공과입출고/README.md) | 위탁지시, 실물 이동, 파트너 실적과 MES 확인 |
| [계획수립과 재계획](04_계획수립과재계획/README.md) | 엔진이 계산한 계획안과 생산관리자가 채택한 계획 버전 |

프로세스마다 시작 사건, 종료 조건, 역할별 인계, 실패 시 업무 경로, 참여 시스템과 기능 설계 링크를 기록한다. 화면 필드와 개별 함수의 구현 규칙은 해당 기능 설계에서 관리한다.
