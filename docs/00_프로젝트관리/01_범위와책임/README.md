# 구축 범위와 책임

| MES팀 구축 대상 | 고유 산출물 | 인접 영역과 맞출 사항 |
|---|---|---|
| 냉연 MES | 14개 업무 기능별 통합설계서, 현장 업무 흐름과 실행 결과 | 영업포털·SAP·현장 시스템과의 인계 시점, 표준 적용 버전 |
| 표준관리시스템 | 기준정보관리, 표준용어관리 기능과 변경·배포 흐름 | 데이터 항목별 생성·승인·배포·수신 주체, 적용일과 배포 실패 처리 |
| 위성시스템 · 파트너 포털 | 협력사 업무와 가공·입출고 내역 처리 설계 | MES 작업지시·실적과 대사하는 키, 협력사별 자료 접근 |
| 위성시스템 · 생산계획 최적화엔진 | 입력과 제약, 계획안 산출·재계산·결과 반환 설계 | MES 확정계획과 엔진 제안의 구분, 취소·변경 반영 시점 |

표는 **시스템 구축 주체**를 나타낸다. 품목·용어·공정의 업무 소유자나 SAP 마스터 수정 권한은 항목별로 기록한다. 예컨대 규격약호의 이름·정의, SAP 자재코드와의 대응, MES 주문검사에서의 사용 조건은 담당자가 서로 다를 수 있다. [데이터와 연계](../../50_데이터와연계/README.md)

SAP S/4HANA, 영업포털, Level 1.5/2, 도성시스템, F-MES, EIS/BI 등은 구성도에서 식별한 주변 시스템이다. 연계대장에는 업무 시나리오를 확인한 뒤 송신·수신 주체, 자료, 방향, 근거, 담당자를 기입한다. 구성도상의 신규·개선은 범위 속성으로 남긴다.
