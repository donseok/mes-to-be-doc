# 재편성과 계획 채택

설비 정지·긴급 주문·품질 보류에 따른 재편성 요청과 후보 비교, 담당자의 채택·반려 및 MES 계획 반영을 설계한다.

- **검토 시나리오** · 계산 도중 입력 변경, 확정된 작업의 동결, 오래된 결과 채택 차단, 동일 결과의 중복 반영
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
