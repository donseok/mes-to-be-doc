# 위성시스템

파트너 포털과 생산계획 최적화엔진은 MES팀의 구축 대상이다. 각 시스템의 사용자 업무와 처리 로직에 별도 기능 설계서를 두고, MES나 표준관리시스템과 주고받는 인터페이스는 공통 명세에 연결한다.

| 구축 시스템 | 주된 사용자 | 설계 경계 |
|---|---|---|
| [파트너 포털](01_파트너포털/README.md) | 협력사 담당자, 사내 업무 담당자 | 외부 사용자의 지시 확인·실적 제출·정정, 업체별 접근 범위 |
| [생산계획 최적화엔진](02_생산계획최적화엔진/README.md) | 생산계획 담당자 | 계획 입력·제약, 최적화 실행·결과, 재편성과 채택 연계 |

예를 들어 엔진에 후보 일정이 생성되는 과정은 엔진 설계에, 후보 일정을 현업이 확정해 작업에 반영하는 정책은 [MES 판매·생산계획](../01_냉연MES/02_판매생산계획/README.md)에 기록한다. 양쪽의 요청·응답과 실패 시 처리는 [시스템 간 인터페이스](../../50_데이터와연계/03_인터페이스/)에서 한 건의 계약으로 관리한다.
