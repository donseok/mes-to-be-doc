# 기존 검토자료

| 자료 | 이용 방법 |
|---|---|
| MTO·MTS 병행운영 | 본문, 상세 1~6, 장표 22장과 재생성 도구를 같은 디렉터리에 둔다. 코일·주문 매칭, SAP 원가, 재고전환에 관한 검토 배경과 미결 사항을 찾을 수 있다. [본문](MTO-MTS_병행운영/mto-mts-hybrid-analysis.md) · [장표](MTO-MTS_병행운영/slides/README.md) |
| 품질설계 프로세스 | ‘주문정합성체크’ 탭의 단계 번호를 근거로 인용한다. 주라인·대체라인의 선정 기준처럼 시트에서 질문으로 남긴 부분은 검토 상태를 유지한다. [원본 시트](https://docs.google.com/spreadsheets/d/1Rjccj6EcFQNFdUkx-suyEFDLEI-MArmDhq0QCyIFmjo/edit) |
| 현행 MES 위키 | 기존 코일 진행상태, 모듈·DB 조사 결과를 확인한다. 검토한 항목은 새 설계서에서 버전이나 조사 시점과 함께 인용한다. [Drive 위키](https://drive.google.com/drive/folders/1euwtQB-Ks9JlCw4Bh0vuSdQgbz9GLwzI) |

위 자료는 설계의 근거다. 업무 담당자가 채택한 동작과 실제 적용할 판정식·계약·예외는 대상 기능의 통합설계서에서 정한다.
