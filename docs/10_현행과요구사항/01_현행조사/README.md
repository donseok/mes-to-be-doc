# 현행조사

현장 조사 기록에는 공장·라인·업무, 관찰한 시스템과 버전, 작성일, 업무 단계, 확인 근거를 적는다. 정상 처리와 예외 수작업을 함께 적으면 재구축에서 보존할 동작과 바꿀 동작을 비교할 수 있다.

냉연 업무라면 코일 분할·합권 후 이력 조회, 품질 보류 후 라인 투입, 현장 실적과 ERP 입고 시점 차이처럼 업무 경계를 넘는 사례도 조사 대상으로 삼는다. 조사에서 확인한 문제는 요구사항 목록과 연결한다. [현행 위키](https://drive.google.com/drive/folders/1euwtQB-Ks9JlCw4Bh0vuSdQgbz9GLwzI)
