# 계획 입력과 제약

수주·납기, 라인별 가용 시간, 재공·재고, 작업 간 선후관계 등 입력 후보를 검토한다. 필수 제약과 목표 우선순위, 데이터 시점, 단위와 누락값 처리 방법을 정한다.

- **검토 시나리오** · 설비 캘린더 충돌, 이미 투입한 작업, 가중치 변경 권한, 계획 기간 경계
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
