# 품질판정

시험·검사 결과를 품질 기준과 비교해 코일의 품질상태를 결정·변경하는 업무를 다룬다.

- **기능 후보** · 검사 실적 수신, 판정, 보류·해제, 재판정 이력
- **설계할 때 정할 점** · 검사 미완료와 부적합을 구분하고, 출하 편성 후 재판정 시 조치 권한을 정한다.
- **연관 업무** · [품질설계](../08_품질설계/README.md) · [출하관제](../12_출하관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
