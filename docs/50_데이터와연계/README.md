# 데이터와 연계

여러 기능과 시스템이 함께 읽고 쓰는 데이터의 의미, 책임, 교환 규격을 정의한다. 통합설계서는 필요한 데이터와 인터페이스를 ID·경로·버전으로 참조한다.

| 질문 | 원본 위치 |
|---|---|
| 코일·주문·생산지시·실적은 어떤 키로 연결되고 상태는 언제 바뀌는가? | [데이터 모델](01_데이터모델/README.md) |
| 용어·코드의 의미, 승인 주체, 원본과 수신처는 어디인가? | [표준코드와 소유권](02_표준코드와소유권/README.md) |
| 시스템 간 무엇을 어떤 시점에 보내고, 실패한 건은 어떻게 복구하는가? | [인터페이스](03_인터페이스/README.md) |
| 기존 데이터를 목표 모델로 어떤 규칙에 따라 옮겨 대사하는가? | [이행 매핑](04_이행매핑/README.md) |

표준관리시스템 자체의 등록·검토·개정·배포 기능은 시스템 설계에 기술한다. 이 폴더에는 각 시스템이 실제로 적용하기로 한 공통 정의와 교환 계약을 둔다. [시스템별 설계](../40_시스템설계/README.md)
