# 원·부재료관리

원료 코일과 부재료의 수급·가용·사용량을 확인하고 현장 재고를 관리하는 업무를 다룬다.

- **기능 후보** · 입고 확인, 사용 예정량과 가용량 비교, 소모·반납 실적
- **설계할 때 정할 점** · 계량 단위와 환산, 실물·장부 불일치, 투입 취소 시 재고 복구 책임을 정한다.
- **연관 업무** · [라인투입관리](../05_라인투입관리/README.md) · [야드관리](../10_야드관리/README.md) · [파트너포털](../../03_위성시스템/01_파트너포털/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
