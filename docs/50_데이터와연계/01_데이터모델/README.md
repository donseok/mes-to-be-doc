# 데이터 모델

업무 개념·관계, 논리 모델, 시스템별 물리 매핑을 구분한다. 여러 시스템에 존재하는 같은 항목의 생성·정정 책임은 [소유권 대장](../02_표준코드와소유권/소유권대장.csv)과 연결한다.

| 정의 단위 | 작성할 내용 |
|---|---|
| 엔터티 | 업무 정의, 업무 키·시스템 키, 식별 범위, 원본 시스템, 생성·종료 조건, 관계의 다중성 |
| 속성 | 이름과 표준 용어, 타입·길이·정밀도, 단위, 허용 값, 필수·누락·빈 값 처리, 적용 시각과 기록 시각 |
| 상태와 이력 | 이전·다음 상태, 전이 조건·행위자, 취소·정정 가능 시점, 원거래 ID, 이력 조회 기준 |
| 시스템별 매핑 | 저장 테이블·필드와 키, 버전, 변환 규칙, 소수점 처리, 마스터 참조·유효기간 |

냉연 업무에서는 코일 분할·합권의 부모와 자식 관계, 중량과 단위, 주문 귀속 변경 전후의 이력과 시점을 정의 대상으로 검토한다. 물리 테이블명이나 상태값은 대상 시스템에서 확인된 뒤 모델에 넣는다.
