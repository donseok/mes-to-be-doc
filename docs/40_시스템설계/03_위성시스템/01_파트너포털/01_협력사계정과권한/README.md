# 협력사 계정과 권한

협력사·사업장·업무 역할별로 주문과 실적의 접근 범위를 설계한다. 위탁 처리와 납품을 함께 담당하는 경우의 권한 조합, 위임·권한 회수 후 열린 요청의 처리도 검토한다.

- **검토 시나리오** · 타사 거래번호로 조회를 시도했을 때의 결과, 공장 간 겸직자의 허용 범위, 대리 등록자 식별
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
