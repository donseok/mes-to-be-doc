# 냉연 MES

첨부 구성도의 14개 업무를 그대로 찾아갈 수 있는 기능 색인이다. 각 업무 폴더에는 설계할 기능 후보와 검토 질문이 있다. 하나의 기능이 여러 업무에 걸치면 상태를 바꾸거나 판단을 내리는 업무에 설계서 한 건을 두고 관련 업무에서 그 문서를 연결한다.

| 업무 | 설계 주제 예시 |
|---|---|
| [기준정보](01_기준정보/README.md) | 라인·설비 적용 기준 조회, 전사 코드 수신·적용 |
| [판매·생산계획](02_판매생산계획/README.md) | MTO·MTS 물량 구분, 계획 버전 비교 |
| [납기관리](03_납기관리/README.md) | 납기 응답, 지연 대상 추출 |
| [원·부재료관리](04_원부재료관리/README.md) | 입고 확인, 사용 예정량과 가용량 비교 |
| [라인투입관리](05_라인투입관리/README.md) | 투입 대기열, 코일 식별 |
| [조업관리](06_조업관리/README.md) | 작업 실적 등록, 코일 계보 추적 |
| [생산관제](07_생산관제/README.md) | 라인 진행 현황, 작업지시 대비 실적 |
| [품질설계](08_품질설계/README.md) | 주문정합성검사, 생산가능라인 확인 |
| [품질판정](09_품질판정/README.md) | 검사 실적 수신, 판정 |
| [야드관리](10_야드관리/README.md) | 적치 가능 위치, 위치 변경 확인 |
| [사내운송](11_사내운송/README.md) | 운송 요청, 진행 상태 |
| [출하관제](12_출하관제/README.md) | 출하 편성, 품질 보류 확인 |
| [통합관제](13_통합관제/README.md) | 코일의 공정 간 진행 추적, 생산·품질·출하 지연 연계 조회 |
| [출력물관리](14_출력물관리/README.md) | 라벨과 작업표 발행, 서식 적용일 관리 |

업무 전체 흐름은 [목표업무](../../20_목표업무/), 승인된 공통 코드 정의와 시스템 간 데이터 계약은 [데이터와 연계](../../50_데이터와연계/)에서 찾는다. 기본·상세 내용을 함께 기록할 때는 [통합설계서 양식](../../90_작성표준/통합설계서_양식.md)을 사용한다.
