# 표준코드와 소유권

용어·코드를 제·개정하는 기능은 표준관리시스템의 설계서에 둔다. 업무 항목별 원본과 변경 권한은 여기에서 정하고 각 시스템 설계가 참조한다. 표준관리시스템, 냉연 MES, SAP의 품목·규격·단위 코드가 겹치는 항목은 표준 승인 주체, 실제 입력 주체, 원본 보유 시스템, 수신 시스템을 각각 확인한다.

[소유권 대장](소유권대장.csv)의 초안 두 행은 작성 예시다. 행별로 담당 부서·원본 시스템을 확인한 뒤 승인 근거와 적용 버전을 추가한다. 승인된 코드 정의에는 업무 키, 표시명, 허용 값, 유효 시작·종료, 폐기 코드의 과거 실적 조회 방식과 대체 코드가 있는지 기록한다. 현장별 확장 값에는 적용 공장·라인을 명시한다.

예를 들어 규격약호의 등록·승인 화면은 시스템 설계서에, 약호의 뜻과 적용 범위는 소유권 대장과 코드 정의에, 약호 변경을 전송하는 메시지는 [인터페이스](../03_인터페이스/README.md)에 둔다.
