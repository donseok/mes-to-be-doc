# 현행과 요구사항

업무를 관찰해 얻은 사실, 새 시스템에서 달성할 요구, 기존에 작성한 검토자료를 각각 찾는 곳이다. 요구를 채택하면 영향을 받는 목표 프로세스와 기능 설계에서 같은 요구사항 ID를 참조한다.

- [현행조사](01_현행조사/README.md) — 업무 인터뷰, 화면·배치·DB·연계 관찰, 현행 예외와 문제
- [요구사항](02_요구사항/README.md) — 출처, 요구 결과, 범위, 상태와 추적 정보
- [기존검토자료](03_기존검토자료/README.md) — MTO·MTS 검토 문서, 품질 시트와 기존 위키의 위치
