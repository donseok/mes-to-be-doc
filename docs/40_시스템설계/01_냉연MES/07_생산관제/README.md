# 생산관제

라인별 계획·진행·지연을 모니터링하고 현장 담당자가 조치하는 업무를 다룬다.

- **기능 후보** · 라인 진행 현황, 작업지시 대비 실적, 정지·지연의 확인과 조치
- **설계할 때 정할 점** · 실시간 설비값과 확정 실적의 기준시각, 지연 판정과 해제 조건을 정한다.
- **연관 업무** · [조업관리](../06_조업관리/README.md) · [통합관제](../13_통합관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
