# 사내운송

공장 내 반송 요청에서 배차·인수·이동 완료까지의 업무를 다룬다.

- **기능 후보** · 운송 요청, 진행 상태, 상하차 완료, 취소
- **설계할 때 정할 점** · 실물 인계 시점, 중복 완료 신호, 운송 중 목적지 변경과 야드 반영 시점을 정한다.
- **연관 업무** · [야드관리](../10_야드관리/README.md) · [출하관제](../12_출하관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
