# 파트너 포털

위탁임가공·부재료·사외창고·도료사의 외부 사용자와 사내 담당자가 같은 거래의 지시, 확인, 예외를 추적하는 위성시스템이다. 거래 기능과 협력사별 열람·대리입력 권한을 함께 설계한다.

| 업무 영역 | 설계 범위와 검토 사항 |
|---|---|
| [협력사 계정과 권한](01_협력사계정과권한/README.md) | 타사 거래번호로 조회를 시도했을 때의 결과, 공장 간 겸직자의 허용 범위, 대리 등록자 식별 |
| [위탁임가공](02_위탁임가공/README.md) | 부분 완료, 불량·잔재 회수, 동일 실적 재제출 및 지시 변경 후 입력 |
| [부재료·도료사](03_부재료와도료사/README.md) | 발주 대비 부분 납품, LOT·단위 차이, 신고 수량과 입고 수량의 대사 |
| [사외창고](04_사외창고/README.md) | 코일번호 불일치, 미인수, 분할 출고, 장부와 현물의 차이 |

아래 기능은 세부 범위를 협의할 때의 출발점이다. [시스템 간 송수신 명세](../../../50_데이터와연계/03_인터페이스/) · [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
