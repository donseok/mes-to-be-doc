# 성능과 복구

목표값을 합의할 때 업무, 측정 구간, 부하 조건, 목표, 측정 방법, 근거와 검증 책임자를 함께 적는다. 시간·용량 목표의 단위와 백분위 또는 최댓값 기준을 명시한다.

| 사례 | 설계와 시험에서 함께 확인할 항목 |
|---|---|
| 영업포털의 주문 검사 | 요청 접수부터 응답까지의 시간, 동시 주문 수, 기준정보 버전, 시간 초과 응답과 재시도 영향 |
| 현장 실적 수집 | 라인별 최대 이벤트 수, 순서 역전·중복·통신 단절, 임시 저장 한도, 재연결 후 누락 건 대사 |
| 생산계획 재편성 | 입력 시점과 버전, 계산 제한시간, 직전 실행과 새 실행의 구분, 채택된 계획 복구 절차 |
| 데이터 복구 | 업무별 허용 중단 시간과 허용 데이터 손실, 복구 시점 선택, 복구 후 코일 상태·수량·인터페이스 이력 대사 |

모니터링 기준과 장애 시 판단 절차는 이곳에 정의하고, 실행 기록·경보 결과·인계 연락망은 운영 문서에서 관리한다.
