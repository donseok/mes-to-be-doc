# 실행과 결과

실행 요청에서 후보 일정·미배정 사유를 돌려주는 과정과 이력을 설계한다. 계산 실패, 시간 제한, 조건상 배정 불가를 구분해 어떤 결과를 제시할지 정한다.

- **검토 시나리오** · 동일 입력·엔진 버전으로 재현할 조건, 부분 결과 표시, 이전 실행 결과와 비교
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
