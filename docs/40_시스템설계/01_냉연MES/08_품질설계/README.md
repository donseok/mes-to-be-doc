# 품질설계

주문 사양과 기준정보에서 생산 가능 여부, 라우팅 및 라인별 설계조건을 도출하는 업무를 다룬다.

- **기능 후보** · 주문정합성검사, 생산가능라인 확인, 규격약호 조회, 라인별 품질설계
- **설계할 때 정할 점** · 주라인·대체라인의 선택 기준, 적용 규격 버전, 최종 확인 시점을 정한다.
- **연관 업무** · [기준정보](../01_기준정보/README.md) · [품질판정](../09_품질판정/README.md)

[주문정합성검사 통합설계서 작성 예시](주문정합성검사/설계서.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
