# 의사결정

| 구분 | 현재 결정 | 근거 |
|---|---|---|
| 구축 범위 | MES팀이 냉연 MES와 표준관리시스템을 구축한다. 위성시스템에는 파트너 포털과 생산계획 최적화엔진을 두고 두 시스템 모두 구축 대상으로 다룬다. | 프로젝트 요청과 첨부 시스템 구성도 |
| 설계 산출물 | 기능별 설계서 한 건에 업무의 목적·경계와 구현 상세를 함께 기록한다. 프로젝트 수행 팀원과 구현 AI가 같은 버전을 읽는다. | 프로젝트 요청 |

추가 결정은 쟁점, 검토한 선택지, 결정 내용과 이유, 영향 기능·계약, 결정자, 결정일과 적용 버전을 기록한다. 결론을 기다리는 질문에는 영향과 담당 역할을 적어둔다. 기존 MTO·MTS 검토자료의 D1~D24는 출처의 번호를 유지하고, 이번 설계에 채택한 항목에서 그 번호를 인용한다.
