# 출력물관리

현장 작업·식별·출하에 사용하는 서식과 발행·재발행 이력을 다룬다.

- **기능 후보** · 품질보증서·검사증명서·Tag·부재료 라벨의 발행, 서식 적용일, 재출력 이력
- **설계할 때 정할 점** · 재발행 권한, 코일 분할이나 출하 취소 때 기존 출력물의 효력을 정한다.
- **연관 업무** · [조업관리](../06_조업관리/README.md) · [출하관제](../12_출하관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)

## 출력물 공통 설계 항목

- 출력물별 발행 단위, 발행 트리거, 서식 버전과 적용일을 기록한다.
- 필드의 원본과 발행 시점에 확정한 값, 누락 시 발행 중단 또는 보완 절차를 정한다.
- 최초 발행, 동일 내용 재출력, 내용 정정 후 재발행, 무효 처리를 구분하고 발행번호·권한·감사 이력을 정한다.
- 문서형은 서식·언어·페이지, 식별물은 인쇄 규격과 바코드 스캔의 인수 기준을 기능별로 정한다.
