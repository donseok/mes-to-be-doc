# 단위·연계계약 시험

개발자는 기능 안의 판단 규칙을, 송수신 담당자는 양쪽이 같은 요청과 응답을 해석하는지를 확인한다. 아래는 설계 검토 후 선택할 시험 후보다.

| 시험 대상 | 확인할 사례 |
|---|---|
| 표준관리시스템과 MES | 코드의 효력 시작일 전후 조회 결과와 변경 통보에서 사용하는 버전을 각각 확인한다. |
| MES 품질·계획 | 규격 경계값과 생산가능라인이 없는 경우를 기능 AC와 대조한다. |
| 파트너 포털 | 같은 위탁 실적을 두 번 보냈을 때 접수 이력과 MES 반영 건수를 대조한다. |
| 생산계획 최적화엔진 | 계산 가능한 입력, 제약 위반 입력, 결과 없는 입력에서 반환하는 상태와 사유를 비교한다. |

단위시험에는 조건·기대값·실제값을 남긴다. 계약시험에는 기능 AC와 연계 명세 버전, 비식별 요청·응답, 송수신 빌드, 메시지 식별자와 양쪽 판정을 연결한다. 상대 시스템을 모의한 경우 모의 범위를 적어 실제 시스템과의 통합시험에서 이어서 확인한다.
