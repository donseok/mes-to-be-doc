# 이행 매핑

현행에서 목표 시스템으로 옮길 데이터의 변환·검증 규칙을 보관한다. 작업 시간표·실행 순서, 리허설 또는 본이행 실적은 이행·운영 문서에서 이 규칙의 버전과 실행 회차를 참조한다.

| 기록 단위 | 필요한 내용 |
|---|---|
| 이행 대상 | 데이터셋, 기준시점, 원천·대상 시스템, 대상 범위와 제외 근거, 업무 승인자 |
| 필드와 키 | 원천 필드·업무 키, 대상 필드와 타입, 변환식, 코드 대응, 누락·중복·폐기 값 처리 |
| 재실행 | 추출 기준시각, 증분 범위, 이미 반영한 행 판별 및 정정 방식, 복구·원복 조건 |
| 대사 | 비교 키와 집계 단위, 건수·중량·금액 중 해당 지표, 허용 오차·승인 주체, 차이 건 검토 방법 |

예를 들어 코일 재고 이행은 공장·보관위치·자재·코일과 주문 귀속별 수량 및 중량을 대사할지 검토한다. 생산 중 코일과 출하 대기 코일처럼 기준시점에 진행 중인 건은 상태와 선행 문서 연결을 함께 대조한다. 실제 기준시점, 반올림 단위와 허용 오차는 현업·시스템 담당자의 결정 근거를 남긴다.
