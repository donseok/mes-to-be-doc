# 표준용어관리

업무용어의 뜻, 이름, 동의어, 적용 업무와 데이터 항목 참조를 관리하는 기능을 설계한다. 현업이 사용하는 명칭과 프로그램 필드 이름을 연결할 때 두 값이 같은 뜻인지 정의와 사용 사례를 검토한다.

- **기능 후보** · 용어 제안·검색, 동의어 연결, 표준 정의 개정, 폐기된 명칭의 후속 용어 조회
- **인수 조건 검토** · 같은 이름의 다른 개념, 뜻이 같은 두 용어, 용어 변경 후 이전 설계서의 검색·이력 조회
- **연계** · [변경승인과 배포](../03_변경승인과배포/README.md) · [데이터와 연계](../../../50_데이터와연계/)

확정한 기능은 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
