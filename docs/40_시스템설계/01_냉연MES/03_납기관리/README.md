# 납기관리

수주 품목의 약속납기와 계획·실적상 예상 완료시점을 대조하는 업무를 다룬다.

- **기능 후보** · 납기 응답, 지연 대상 추출, 재편성 후 납기 영향 확인
- **설계할 때 정할 점** · 시간 기준과 휴무일, 부분 생산·분할 출하 시 약속 단위를 정한다.
- **연관 업무** · [판매·생산계획](../02_판매생산계획/README.md) · [출하관제](../12_출하관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
