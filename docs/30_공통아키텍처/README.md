# 공통 아키텍처

냉연 MES, 표준관리시스템, 파트너 포털, 생산계획 최적화엔진이 함께 지킬 기술 기준을 보관한다. 기능 설계서에서는 적용할 기준의 경로와 버전을 가리키고, 그 기능에만 해당하는 예외를 설명한다.

| 설계할 때의 질문 | 원본 위치 |
|---|---|
| 현장과 업무망 사이에서 무엇이 실행되고 어떤 순서로 배포되는가? | [시스템 구성과 배포](01_시스템구성과배포/README.md) |
| 누가 어느 법인·공장·라인·협력사의 데이터를 다룰 수 있는가? | [보안과 권한](02_보안과권한/README.md) |
| 피크 부하, 현장 통신 단절, 복구 후 대사를 어떻게 검증할 것인가? | [성능과 복구](03_성능과복구/README.md) |
| 팀원과 AI가 어느 코드 위치와 공통 구현 규칙을 따라야 하는가? | [개발 표준](04_개발표준/README.md) |

의사결정 기록에는 적용 시스템·환경, 선택 이유, 결정 상태, 시행 버전, 검토자와 관련 설계서를 남긴다. 프로젝트에 채택된 값과 제품은 이 기록에서 확인한다. 아래 하위 안내에 제시한 측정 항목과 기술 형식은 설계를 작성할 때 사용할 예시다.
