# 통합시험과 사용자 인수시험

통합시험(SIT)은 시스템 사이에 값과 상태가 의도대로 이어지는지를 확인한다. 사용자 인수시험(UAT)은 해당 업무 담당자가 결과를 보고 다음 업무를 수행할 수 있는지 판정한다. 한 사례를 두 번 사용할 때는 각각의 판정과 증적을 남긴다.

| 시험 후보 | 통합시험에서 볼 연결점 | 인수시험에서 확인할 사람과 결과의 예 |
|---|---|---|
| MTS 코일을 MTO 주문에 충당 | MES 코일·주문 품목과 SAP 재고 구분, 재전송 전후 수량 | 생산관리·출하 담당자가 주문에 귀속된 코일과 출하 가능량을 확인한다. |
| 표준코드 변경 후 계획 재계산 | 표준 버전, MES 계획 입력, 최적화엔진 결과 버전과 채택 이력 | 계획 담당자가 바뀐 제약을 확인하고 적용할 결과를 고른다. |
| 위탁가공 실적 수신 | 포털 접수 번호와 MES 입고·품질 상태의 대응 | 협력사와 입고 담당자가 정정 접수 및 처리 결과를 각자 확인한다. |

사용할 기준 데이터, 시스템별 시작·종료 상태, 연결할 AC, 빌드·메시지 식별자를 남긴다. 현업 판정에는 담당 업무, 승인·조건부·보류 사유, 잔여 결함과 재확인 결과를 연결한다. MTO·MTS 사례의 숫자와 미결 가정은 시험 설계 시 구분한다. [기존 프로세스 시뮬레이션](../../10_현행과요구사항/03_기존검토자료/MTO-MTS_병행운영/mto-mts-05-process-simulation.md)
