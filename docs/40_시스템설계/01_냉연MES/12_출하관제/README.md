# 출하관제

출하 대상 코일을 확정하고 상차·출하 결과가 납품에 연결되는 업무를 다룬다.

- **기능 후보** · 출하 편성, 품질 보류 확인, 상차 확인·취소, 출하 실적
- **설계할 때 정할 점** · 납품 품목과 코일의 대응 관계, 이미 상차된 코일의 정정·대사를 정한다.
- **연관 업무** · [품질판정](../09_품질판정/README.md) · [사내운송](../11_사내운송/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
