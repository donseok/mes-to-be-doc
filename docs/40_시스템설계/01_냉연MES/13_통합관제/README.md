# 통합관제

생산·품질·물류에 걸친 진행 상태와 예외를 종합해 현업이 영향과 조치 순서를 판단하는 업무를 다룬다.

- **기능 후보** · 코일의 공정 간 진행 추적, 생산·품질·출하 지연 연계 조회
- **설계할 때 정할 점** · 같은 코일의 상태가 다르게 보일 때 표시 우선순위와 원본 화면 연결, 집계 기준시각을 정한다.
- **연관 업무** · [생산관제](../07_생산관제/README.md) · [품질판정](../09_품질판정/README.md) · [출하관제](../12_출하관제/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
