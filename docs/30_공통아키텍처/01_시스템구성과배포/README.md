# 시스템 구성과 배포

구성도를 읽고 운영자가 장애 지점을 찾거나 특정 릴리스를 복구할 수 있는 수준으로 기록한다.

| 산출물 | 필요한 내용 |
|---|---|
| 시스템 경계도 | 네 구축 시스템의 업무 책임, 외부 상대, 호출 주체, 데이터 방향, 현장과 중앙 경계. 연계 확인 상태를 함께 표기한다. |
| 실행·배치 구성도 | 서비스·배치·저장소·현장 어댑터별 실행 위치, 기동 순서, 의존 서비스와 장애 시 영향. 실제 제품명과 배포 단위는 선정 후 기록한다. |
| 환경·릴리스 구성표 | 개발·통합시험·운영 환경별 설정 책임, 버전 조합, 배포 순서, 이전 버전과의 호환 범위, 롤백 시 데이터 처리. 설정 키와 비밀 관리 위치를 참조한다. |

예를 들어 현장 실적 수집기의 위치를 바꿀 때에는 영향을 받는 라인, 중단 중 보관 주체, 수집 재개 시점, 복구를 확인할 지표까지 연결한다. 송수신 필드 원본은 [인터페이스](../../50_데이터와연계/03_인터페이스/README.md)에서 관리한다.
