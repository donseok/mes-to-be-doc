# 데이터 이행과 대사

대상별 원천·대상 키, 추출 기준 시각, 변환 규칙 버전, 누락·중복 처리, 대사 책임자를 먼저 정한다. 이행 회차별로 원천 추출본과 적재 결과의 식별자, 건수·수량·차이 사유, 재실행 후 확인 결과를 보관한다.

| 이행 후보 | 확인할 내용 |
|---|---|
| 공통·현장 기준정보 | 적용 버전·효력일·코드 매핑과 미매핑 건, MES·포털·엔진에서 참조하는 코드의 유효성을 확인한다. |
| 미결 주문·작업지시·재공 | 주문 품목별 잔량과 지시별 공정·진척, 진행 중 코일의 마지막 확정 공정과 보류 상태를 같은 기준 시점에 맞춘다. |
| 코일·재고 | 코일 식별자와 SAP 배치 대응을 확인한다. 일반재고와 판매오더재고(특수재고 E)를 구분해 코일 수·중량을 비교하고 E 재고는 주문 번호·품목별 차이까지 추적한다. |
| 포털·최적화엔진의 진행 건 | 미완료 위탁 접수, 외부창고 잔량, 실행 중인 계획·채택된 계획 버전을 인계할지 재접수·재계산할지 정하고 그 근거를 남긴다. |

중량 단위·반올림과 허용 차이는 대상별로 합의한다. 총량이 맞아도 코일·주문 귀속이 바뀐 경우를 찾아낼 수 있게 상세 대사를 남긴다. 차이는 보정 담당, 재대사 결과, 가동 판정에 미치는 영향까지 기록한다. [기존 MTO·MTS 설계 검토자료](../../10_현행과요구사항/03_기존검토자료/MTO-MTS_병행운영/mto-mts-04-mes-requirements.md)
