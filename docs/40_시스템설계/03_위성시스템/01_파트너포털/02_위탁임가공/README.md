# 위탁임가공

위탁 지시, 수탁 확인, 소재 인계, 가공 실적과 반입 결과를 하나의 거래로 추적하는 방안을 설계한다. MES가 실적을 확정하는 시점과 파트너가 입력한 실적의 정정 절차를 정한다.

- **검토 시나리오** · 부분 완료, 불량·잔재 회수, 동일 실적 재제출 및 지시 변경 후 입력
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
