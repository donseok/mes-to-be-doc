# 시스템별 통합설계

MES팀은 냉연 MES, 표준관리시스템, 위성시스템인 파트너 포털과 생산계획 최적화엔진을 구축한다. 업무가 여러 시스템에 걸쳐 있으면 목표업무의 시나리오에서 기능별 설계서와 시스템 간 계약을 연결한다.

| 구축 대상 | 설계할 업무 | 처음 찾아갈 곳 |
|---|---|---|
| 냉연 MES | 계획·품질·생산·물류 등 14개 업무의 현장 기능 | [14개 업무 색인](01_냉연MES/README.md) |
| 표준관리시스템 | 기준정보와 표준용어를 관리하는 기능, 승인·배포 절차 설계 | [기준정보·용어·변경관리](02_표준관리시스템/README.md) |
| 위성시스템 · 파트너 포털 | 협력사의 요청·제출·조회, 사내 담당자와의 인계 | [파트너 포털](03_위성시스템/01_파트너포털/README.md) |
| 위성시스템 · 생산계획 최적화엔진 | 후보 계획 계산, 제약·결과, 재편성과 계획 채택 연계 | [생산계획 최적화엔진](03_위성시스템/02_생산계획최적화엔진/README.md) |

## 구현 단위와 원본 위치

1. 업무별 목차의 ‘기능별 폴더’에서 해당 기능을 찾아 `설계서.md`를 작성한다. 기본설계와 상세설계를 한 문서에 이어 쓰고, 같은 기능의 검토 의견·결정·인수조건을 동일한 식별자로 추적한다. [통합설계서 양식](../90_작성표준/통합설계서_양식.md)
2. 부서 간 인계와 시스템 간 선후관계는 [목표업무](../20_목표업무/)에, 공통 인증·권한과 기술 결정은 [공통아키텍처](../30_공통아키텍처/)에 둔다. 기능 설계에는 해당 기능에서 달라지는 조건을 적는다.
3. 속성의 원본과 변경 권한, 공유 데이터와 연계 명세는 [데이터와 연계](../50_데이터와연계/)에서 연결한다. 구현·검증 담당자는 설계서에 명시한 계약과 인수 조건의 버전을 함께 사용한다.

SAP S/4HANA, 현장 Level 1.5/2, 도성시스템, F-MES 등 도식에 등장하는 상대 시스템은 대상 업무·데이터·방향을 확인하면서 [인터페이스 대장](../50_데이터와연계/03_인터페이스/)에 등록한다. 이 색인에 쓴 기능 후보와 검토 질문의 확정 여부는 개별 설계서에서 관리한다.

품질보증서·검사증명서·Tag·부재료 라벨의 설계 범위와 공통 발행 규칙은 출력물관리에서 확인한다. [출력물관리](01_냉연MES/14_출력물관리/README.md)
