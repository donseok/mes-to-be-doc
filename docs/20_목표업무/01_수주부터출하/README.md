# 수주부터 출하

검토 흐름은 주문 접수 → 사양 정합성 검사 → 판매·생산계획 → 라인투입·조업 → 품질판정 → 야드·출하다. 각 인계에 주문 품목·작업지시·코일 식별자, 처리 주체와 완료 근거를 적는다. 주문 변경, 품질 보류, 부분 출하에서 정상 흐름으로 복귀하는 조건을 별도로 짚는다.

주문생산과 계획생산에서는 수주와 생산의 선후 관계가 달라진다. 기존 분석의 일반재고 코일 4톤 충당 사례를 재사용할 때는 현업 규칙, SAP 반영, 양쪽 재고 확인 조건을 따로 검토한다. [기존 시뮬레이션](../../10_현행과요구사항/03_기존검토자료/MTO-MTS_병행운영/mto-mts-05-process-simulation.md)
