# 기준정보

설비·라인·작업조 등 현장에서 쓰는 기준과 수신한 전사 코드의 적용 조건을 다룬다.

- **기능 후보** · 라인·설비 적용 기준 조회, 전사 코드 수신·적용, 사용 중단 기준의 조회
- **설계할 때 정할 점** · 변경 전 기준으로 시작한 작업에 어느 버전을 적용할지, 라인 전용 제약을 누가 정정할지 정한다.
- **연관 업무** · [라인투입관리](../05_라인투입관리/README.md) · [기준정보관리](../../02_표준관리시스템/01_기준정보관리/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
