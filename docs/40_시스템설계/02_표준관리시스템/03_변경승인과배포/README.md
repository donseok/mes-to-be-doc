# 변경승인과 배포

기준정보와 표준용어 변경이 요청되어 검토·승인되고 수신 시스템에 적용되기까지의 기능을 설계한다. 승인된 시점, 배포된 시점, 각 시스템에 실제 적용된 시점을 구분해 조회할 수 있도록 상태와 식별자를 정의한다.

- **기능 후보** · 변경요청, 영향 조회, 승인·반려, 배포와 수신결과 확인, 오류 복구·재배포
- **인수 조건 검토** · 예약 배포 전에 취소, 동일 배포본 재수신, 일부 수신처 실패, 잘못된 코드의 정정과 버전 이력
- **연계** · [기준정보관리](../01_기준정보관리/README.md) · [표준용어관리](../02_표준용어관리/README.md) · [시스템 간 인터페이스](../../../50_데이터와연계/03_인터페이스/)

실제 승인자와 상태 전이는 업무별로 정한 뒤 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
