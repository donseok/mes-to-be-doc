# 표준관리시스템

MES팀이 표준관리시스템의 기준정보관리와 표준용어관리 기능을 구축한다. 두 기능에서 함께 쓰는 변경·승인·배포 절차를 한곳에서 설계할 수 있도록 별도 업무 폴더를 둔다.

| 업무 | 포함할 설계 |
|---|---|
| [기준정보관리](01_기준정보관리/README.md) | 표준 코드·속성 정의, 분류·검색, 적용 범위와 유효기간 관리 |
| [표준용어관리](02_표준용어관리/README.md) | 용어·정의·동의어, 도메인과 단위의 참조, 개정 이력 |
| [변경승인과 배포](03_변경승인과배포/README.md) | 변경 요청·검토·승인, 배포 대상·적용 시점·재배포 및 수신 결과 |

## MES 기준정보 및 SAP와의 업무 경계

예를 들어 단위코드의 정의와 이력 유지, 수신 시스템의 로컬 단위 매핑, 이미 시작한 작업의 규격 버전 적용은 서로 다른 책임이다. 표준관리시스템의 등록·승인 기능은 여기서 설계하고, MES 수신 후 현장 적용은 [냉연 MES 기준정보](../01_냉연MES/01_기준정보/README.md)에서 설계한다. 단위코드·자재코드·라인 제약마다 원본과 생성·변경 권한, SAP MD와의 역할을 확인해 [데이터와 연계](../../50_데이터와연계/)에 기록한다. 배포 포맷·응답 등 송수신 규격은 [인터페이스](../../50_데이터와연계/03_인터페이스/)에 둔다.
