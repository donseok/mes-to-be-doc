# 사외창고

창고별 코일 입출고 요청, 실물 확인과 회신, 사외 보관분 재고 대사를 다룬다. 운송 중과 보관 중의 보관 책임, 현장 수불과 MES 재고에 반영하는 시점을 정한다.

- **검토 시나리오** · 코일번호 불일치, 미인수, 분할 출고, 장부와 현물의 차이
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
