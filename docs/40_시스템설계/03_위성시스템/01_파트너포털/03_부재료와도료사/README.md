# 부재료·도료사

부재료 협력사와 도료사의 납품 통지·거래 확인을 다룬다. 공통 납품 절차와 도료별 LOT·포장 단위 등 별도 관리가 필요한 항목은 현업 확인 후 정의한다.

- **검토 시나리오** · 발주 대비 부분 납품, LOT·단위 차이, 신고 수량과 입고 수량의 대사
- **기능 설계 위치** · 범위를 정한 뒤 이 폴더의 `기능명/설계서.md`에 업무 흐름, 입력·결과, 예외와 인수 조건을 함께 기록한다.
