# 생산계획 최적화엔진

계획 입력과 제약을 받아 후보 일정을 계산하고, 계획 담당자가 결과를 검토해 MES에 반영하는 흐름을 다룬다. 실행번호·계획 버전과 입력 기준시각을 연결하면 동일 조건의 결과를 비교할 수 있다.

| 업무 영역 | 설계 범위와 검토 사항 |
|---|---|
| [계획 입력과 제약](01_입력과제약/README.md) | 설비 캘린더 충돌, 이미 투입한 작업, 가중치 변경 권한, 계획 기간 경계 |
| [실행과 결과](02_실행과결과/README.md) | 동일 입력·엔진 버전으로 재현할 조건, 부분 결과 표시, 이전 실행 결과와 비교 |
| [재편성과 계획 채택](03_재편성과계획채택/README.md) | 계산 도중 입력 변경, 확정된 작업의 동결, 오래된 결과 채택 차단, 동일 결과의 중복 반영 |
