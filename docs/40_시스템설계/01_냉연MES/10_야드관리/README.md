# 야드관리

코일의 보관 위치·적치·이동 이력을 현물 단위로 조회하고 정정하는 업무를 다룬다.

- **기능 후보** · 적치 가능 위치, 위치 변경 확인, 실사 차이 관리
- **설계할 때 정할 점** · 위치 식별 단위, 이동 중의 위치 표시, 미확인 이동과 실사 정정 기준을 정한다.
- **연관 업무** · [사내운송](../11_사내운송/README.md) · [원·부재료관리](../04_원부재료관리/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
