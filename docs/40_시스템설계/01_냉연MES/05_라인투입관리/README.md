# 라인투입관리

작업지시에 맞는 투입 대상 코일을 식별하고 라인 투입 가능 여부를 판단하는 업무를 다룬다.

- **기능 후보** · 투입 대기열, 코일 식별, 선행공정 완료·품질 보류 확인
- **설계할 때 정할 점** · 순서 변경, 재투입, 현물 번호 불일치가 생길 때 허용 조건과 기록 방법을 정한다.
- **연관 업무** · [조업관리](../06_조업관리/README.md) · [품질판정](../09_품질판정/README.md)

확정한 기능은 이 폴더 아래 `기능명/설계서.md`에 작성한다. [통합설계서 양식](../../../90_작성표준/통합설계서_양식.md)
