# 전환 리허설과 복귀

리허설 회차별로 대상 빌드·참여 시스템, 중지·재개할 업무, 마지막 처리 번호·시각, 데이터 대사, 진행·중지·복귀 판단과 근거를 기록한다. 가동일에는 승인된 회차의 절차와 실제 수행 결과를 연결한다.

| 판단 지점 | 확인할 예 |
|---|---|
| 입력 마감과 잔여 건 인계 | 표준 배포의 마지막 버전, MES 미완 작업, 포털 미처리 접수, 엔진의 마지막 채택 계획을 같은 기준 시점으로 맞춘다. 마감 뒤 들어온 건의 처리 방법을 정한다. |
| 가동 판단 | 대상별 대사와 대표 업무 시험을 확인하고 미결 차이, 다음 판단 시점, 판단자를 남긴다. 현장 조업·물류·IT 운영 담당은 검토 역할의 예다. |
| 복귀 판단과 검증 | 마지막 복귀 가능 시점, 신·구 시스템 중 접수를 받을 곳, 가동 후 입력된 변경분과 이미 상대에게 전송한 건의 처리 방식을 합의한다. 복귀 리허설에서 이중 반영·미반영을 대사한다. |

회차가 끝나면 소요 시간, 중단 원인, 수정된 절차와 다음 회차의 재확인 항목을 기록한다. 장비 조작과 데이터 복구 실행은 사업장에서 승인한 절차의 위치·버전·담당자를 연결한다.
