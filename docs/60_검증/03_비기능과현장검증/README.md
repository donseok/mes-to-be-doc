# 비기능·현장 검증

현장 사용자와 운영 담당자가 실제 사용 조건을 확인한 기록을 둔다. 시험 조건은 대상 라인·교대·단말 및 시스템, 적용한 빌드와 구성, 측정 구간, 설계서에서 합의한 기준과 연결한다.

- **현장 흐름 후보** — 라인에서 코일 식별표를 읽은 뒤 야드 위치와 작업지시가 맞는지, 스캔이 실패하면 교대자가 어떤 상태를 보게 되는지 확인한다.
- **성능 후보** — 계획 입력 규모와 계산 소요 시간, 피크 시간대 포털 응답과 MES 관제 정보의 표시 지연을 함께 기록한다. 목표값은 해당 기능 AC 또는 합의한 성능 기준에서 가져온다.
- **회복·권한 후보** — 표준 배포 중 지연된 수신처의 버전 확인, 포털 재접속 후 접수 결과 조회, 협력사 간 조회 범위, 계획 계산 중단 후 화면에 남은 상태를 확인한다.

측정값과 현장 관찰 내용을 구분하고 로그·시험 단말 기록이나 비식별 화면을 실행 건에 연결한다. 실환경 대신 모의한 설비나 조건이 있으면 실제 현장 확인이 필요한 항목을 표시한다.
