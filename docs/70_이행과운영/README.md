# 이행과 운영

|---|---|

| 리허설 회차, 시스템별 전환 순서, 가동·중지·복귀 판단 | [전환 리허설과 복귀](02_전환리허설과복귀/README.md) |
| 가동 뒤 감시할 상태, 장애 분류 및 재처리 기록 | [운영 모니터링과 재처리](03_운영모니터링과재처리/README.md) |
| 업무별 교육, 미결 사항과 운영 인수 판정 | [교육과 운영 인수](04_교육과운영인수/README.md) |
