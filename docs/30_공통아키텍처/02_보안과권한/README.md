# 보안과 권한

역할별 권한은 사용자 유형, 대상 자원, 허용 동작, 데이터 범위, 승인 조건을 한 행에 기록한다. 화면·API·배치 중 어느 경로에 적용되고 어떤 로그를 남기는지도 정한다.

| 검토 시나리오 | 명세에 적을 내용 |
|---|---|
| 협력사가 외주 가공 실적을 조회·수정한다 | 업체별 접근 범위, 공장과 위탁 건의 관계, 입력·확정·취소 역할, 타 업체 데이터 요청 시 응답과 감사 기록 |
| 기준정보를 개정·배포한다 | 작성자·검토자·배포 담당자의 권한, 시행일 변경 권한, 이전 값·변경 값·행위자·시각 추적 |
| 시스템이 현장 실적을 전달한다 | 시스템 계정의 허용 동작, 호출 주체 식별, 자격 교체, 통신 단절 후 재전송의 인증 처리 |

프로젝트 자료 열람 권한과 운영 기능의 데이터 권한은 각각 기록한다. 테스트에서 재현할 사용자·업체·라인 식별값은 예시 데이터를 쓴다.
