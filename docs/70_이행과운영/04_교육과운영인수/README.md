# 교육과 운영 인수

시스템과 업무 역할별로 교육 시나리오, 실습 환경·대상 버전, 확인한 기능 AC, 질문과 미결 항목을 남긴다. 다음은 교육 대상과 실습 후보이며 확정된 권한표는 별도로 참조한다.

| 교육 대상 예 | 실습 후보 |
|---|---|
| 표준 담당·MES 기준정보 담당 | 변경 코드의 효력일과 수신 버전을 확인하고 미반영 건을 인계한다. |
| MES 교대자·생산관리 담당 | 조업 실적과 코일 보류·해제 상태를 조회하고 다음 교대에 미완 작업을 넘긴다. |
| 협력사·포털 운영 담당 | 위탁 실적 접수, 반려 사유 조회, 정정 제출과 최종 접수 확인을 연습한다. |
| 계획 담당·엔진 운영 담당 | 계산 결과의 버전과 제약을 확인하고 채택한 계획 또는 재계산 이력을 찾는다. |

운영 인수 기록에는 인계·인수 담당, 대상 빌드와 인수일, 감시·복구 절차 링크, 미해결 결함과 후속 담당, 인수 판정 및 조건을 둔다. 실제 가동 시 사용한 교육 자료와 최종 인수본을 구분하고, 결과 증적은 해당 [시험 기록](../../60_검증/README.md)으로 연결한다.
